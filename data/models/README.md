# Trained Model Weights Directory

This directory stores trained deep learning model weights (such as `unet_flood.onnx` and `unet_flood_best.pth`).

Due to file size constraints, binary model weights are excluded from Git version control.
You can generate or download weights by:
1. Running the training notebook at `p2_ai/notebooks/01_unet_training.ipynb`.
2. Or downloading weights from the Kuro Siwo benchmark repository.
